First you would download the project folder into your computer then you could either run this through your own computer or
by using an IDE. If you chose to run it with an IDE use either Vs Studio code or Eclispe to run our application and make sure you have 
Java installed in either software. Then open the folder in the software you are using and run the program through the App program.
You would then be required to connect to the server using a username you will fill out. Then you will be logged into our main application
where you can test all the functionalites we have to offer. 

If your running through your computer open the terminal or powershell and enter the commands for compiling the project first. This
is important because running the project without compiling will cause problems. Once thats done simply run the program with the standard command for running
java files in terminal or powershell. Once there you simply just follow the instructions I have said in the first option.
